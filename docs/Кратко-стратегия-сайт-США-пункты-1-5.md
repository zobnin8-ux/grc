## 1. Контекст проекта

### 1.1 Задача

Создать **современный американский** многостраничный сайт для industrial-компании на рынке **Houston / Gulf Coast** (mobilization по США — в разумных пределах).

Сайт должен:

- **не** выглядеть как перевод русского сайта;  
- **не** выглядеть как стартап, AI-компания или SaaS-лендинг;  
- **не** выглядеть как «маленький мобильный ремонт в фургоне»;  
- **да** выглядеть как **full-scale Gulf Coast industrial field operations company** с **rapid deployment**;  
- **да** превосходить старых локальных конкурентов (TISS и аналоги) по trust, CTA и первому экрану.

### 1.2 Бизнес-модель (зафиксировано)

| Параметр | Решение |
|----------|---------|
| Россия | Бизнес **полностью в США**. На сайте **нет** России, RU, российских заказчиков |
| Юрлицо | **US LLC** (имя, домен, адрес, телефон, email — **placeholders**) |
| Партнёры | **Не упоминать** |
| Люди | **Все в Америке** |
| Оборудование | **В США** (целевая модель) |
| Язык | **Только English** |
| Capability | Факты с **1grc.ru** → US-структура, EN copy |
| Кейсы на launch | **~6** на EN, **без** имён российских заводов |
| География | **Houston-based**, Gulf Coast + честная строка о wider mobilization |
| Фото | Сток на старте → замена от клиента |
| Insurance / certs | После LLC/полиса; на launch — **гибкий Trust block** |
| Формы (MVP) | **Email** |

### 1.3 Принцип структуры

**Не** 13 равных страниц, а:

> **10 сильных + 2 коротких + 1 hub (карта услуг)**

Полный спектр — в меню; **глубина** — field machining, emergency, shutdown, projects, equipment.

**Сайт:** https://tissinc.com/  
**Профиль:** millwright, field machining, shop machining · refining, petrochemical, power, midstream, offshore · Houston (281.922.7555).

### 2.1 «Сайт Доктор»

| Метрика | Балл |
|---------|------|
| **Общий** | **48** |
| Доверие | 42 |
| **CTA** | **25** |
| Ясность | 55 |

**Плюсы:** структура, три услуги, телефон в шапке, нормальное меню.  

**Минусы:**

1. На **главной нет CTA** (форма только на Contact; номер без `tel:`).  
2. **Нет trust** на главной — шестерёнки, без фото/кейсов/цифр.  
3. Заголовок — *leading provider…* без УТП.  
4. **Нет H1**, нет meta description.  
5. Главная = один экран; flip-карточки с **пустой обратной стороной**.  
6. Сильные цифры (150" VTL, 40' lathe) **спрятаны** в Shop.  
7. Сайт **устарел** (ощущение brochure ~2014).

### 2.2 Вердикт

**TISS — старая визитка, не conversion-ready industrial contractor.**

| | TISS |
|--|------|
| 5 секунд | Отрасли ясны, «почему мы» — нет |
| Proof | Почти ноль на главной |
| Leads | Форма спрятана |

### 2.3 Эталон заголовка (Site Doctor)

**Было:**  
> …leading provider of fixed and rotating machinery services to the refining, petrochemical…

**Надо (логика):**  
> Industrial equipment service for petrochemical and energy — from field repairs to lathe work with diameters up to 150 inches.

### 2.4 Где бить TISS

- Hero + CTA за 5 сек  
- **Projects**, **Equipment**, фото, цифры  
- Формы + emergency; `tel:`; mobile sticky CTA  
- H1, meta, operational dark UI  
- Rapid deployment (карта, urgency)  

**Цель:** выиграть **сравнение за 30 секунд**, не SEO домена за 3 месяца.

## 3. Сравнение с 1grc.ru — уроки

**Сайт:** https://www.1grc.ru/ · SD **48** (ясность **38**, SEO **37**).

### 3.1 Не повторять на US

- Размытый hero («адаптивное производство»).  
- H1 ≠ первый экран.  
- Доверие и кейсы **ниже fold**, простыня отзывов.  
- CTA «обратный звонок» без обещания.  
- Несколько брендов на одном сайте.

### 3.2 Перенести (перепаковать)

- Мобильная обработка на объекте, свои станки.  
- Кейсы: задача → метод → срок.  
- Отрасли → US wording.  
- Сильный title → в **US hero + H1**.

### 3.3 Зеркало

| | 1grc.ru | TISS | **Наш US** |
|--|---------|------|------------|
| SD | 48 | 48 | Выигрыш по **конверсии** |
| Слабое | Витрина | Главная пустая | — |
| Сильное | Контент | Ясность меню | **Витрина + proof** |

## 4. Что значит «убить конкурентов»

**Реалистично:**

- Рядом с TISS наш сайт = **operationally ready**, их = **old brochure**.  
- Заявка **< 2 кликов** на mobile.  
- COI / MSA / ISNet — **после LLC**, не выдумывать на launch.

**Нереалистично на сайте:**

- SEO #1 за месяц  
- Millwright «всё» без capability  
- 24/7 nationwide за 2 часа без диспетчеризации

## 5. Стратегическое позиционирование

### 5.1 Главная идея

**НЕ:** *We are a mobile repair company.*  

**ДА:** *We are a **full-scale industrial field operations company** with **rapid deployment capability**.*

Mobile crews — **преимущество**, не весь бренд.

### 5.2 Целевая реакция

> **“These people look operationally ready.”**

### 5.3 Field-first

| Уровень | Что |
|---------|-----|
| Hero | Field machining, on-site repair, emergency, shutdown, mobile crews |
| Proof | Projects, Equipment, process, trust (гибкий) |
| Меню | Полный спектр на hub; Rotating/Mechanical — коротко или v2 |
| Shop | Поддержка, когда есть US yard |

### 5.4 Millwright vs field machining

- **Field machining** — ядро (металлообработка на объекте).  
- **Millwright** — только если реально в US; не клонировать меню TISS без scope.  
- Launch: **Field + Emergency + Projects + Equipment** глубже остального.

### 5.5 Credibility (без России)

- **Houston-based. Now operating from Houston.**  
- Кейсы без Severstal / Mondelēz и т.д.  
- Факты с 1grc.ru → **рерайт**, не перевод.  
- About (опционально): *decades of in-field machining and proprietary mobile equipment* — без 1grc.ru в публичном поле.
